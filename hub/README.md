# 특수학급 비상호출 (학교 안 설치형)

중계 PC 한 대가 학교 안에서 서버 역할을 합니다. 선생님들은 인터넷 주소 입력 없이 링크만 누르면 됩니다. Node.js 같은 별도 프로그램은 필요 없고, Windows에 기본으로 들어 있는 PowerShell을 사용합니다.

## 관리자(처음 한 번)

1. 중계 PC(Windows)를 학교 와이파이에 연결하고 켜 둡니다.
2. 이 폴더의 [설치하기.bat]을 더블클릭합니다.
3. 관리자 권한 묻는 창이 나오면 [예]를 누릅니다.
4. 학교 이름과 학교 코드(영문 대문자와 숫자 6~12자, 예: NCLB119)를 입력합니다.
5. 설치가 끝나면 바탕화면에 [비상호출 서버 시작] 바로가기가 생깁니다.

## 매일 사용

1. 바탕화면의 [비상호출 서버 시작]을 더블클릭합니다.
2. 검은 창에 표시되는 [선생님 접속 링크]를 선생님들께 전달합니다. 예: http://192.168.0.18:8080/?code=NCLB119
3. 이 창을 닫으면 서버가 꺼집니다. 수업 시간 동안에는 열어 둡니다.

## 외부 접속 (다른 와이파이, 5G)

설치하기.bat을 실행하면 외부 접속 도구(cloudflared)를 함께 받습니다. 서버를 켜면 검은 창에 [다른 와이파이, 5G에서 접속하는 링크]가 표시됩니다. 이 링크는 학교 코드만 알면 어디서나 열립니다. 보안은 학교 코드에만 의존하므로 링크와 코드를 외부에 공유하지 마세요. 무료 임시 주소이므로 서버를 다시 켜면 주소가 바뀝니다.

## 선생님

1. 학교 와이파이에 연결된 휴대폰이나 PC에서 링크를 누릅니다.
2. 이름, 역할, 교실을 입력하고 [입장]을 누릅니다.
3. 비상 호출 버튼을 누르면 같은 학교에 입장한 모든 기기에 알람이 울립니다. [확인했습니다]를 누를 때까지 반복됩니다.
4. 휴대폰은 화면을 켜 둔 상태여야 알람이 울립니다.

## 파일 구성

- 설치하기.bat: 처음 한 번 실행. 관리자 권한 요청, 방화벽·접속 허용 설정, 학교 등록, 바탕화면 바로가기 생성.
- 시작하기.bat: 중계 서버 실행.
- setup.ps1: 설치 작업 본체 (설치하기.bat이 호출).
- server.ps1: 중계 서버 본체 (시작하기.bat이 호출).
- public/: 선생님이 여는 화면 (index.html, app.js, style.css).
- schools.json: 등록된 학교 정보. 설치할 때 자동으로 만들어지며 깃에 올라가지 않습니다.

## 알려진 제한

- 서버를 다시 시작하면 선생님들이 다시 입장해야 합니다 (접속 정보는 서버 메모리에 저장).
- 외부 접속 링크는 무료 임시 주소이며 서버를 다시 켤 때마다 바뀝니다.
- 화면이 꺼지거나 브라우저가 백그라운드로 가면 알람이 늦거나 울리지 않을 수 있습니다.
- 학교 정보 보안 정책에 따라 내부망 8080 포트 사용 허용이 필요할 수 있습니다.
