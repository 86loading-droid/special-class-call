# 비상호출 중계 서버 (학교 내부망 전용)

중계 PC 한 대가 서버 역할을 하고, 같은 학교 와이파이의 휴대폰·태블릿·PC가 접속합니다. 외부 인터넷 주소에서 오는 요청은 서버가 거부합니다.

## 준비 (관리자, 1회)
    node server.js add-school "학교명" "학교코드"
학교 코드는 영문 대문자와 숫자 6~12자입니다. 등록 정보는 hub/schools.json에 저장되며 저장소에는 올라가지 않습니다.

## 실행
    node server.js
시작 화면에 나오는 주소(예: http://192.168.0.10:8080)를 같은 와이파이의 기기에서 엽니다. 학교 코드, 이름, 역할, 교실을 입력하면 입장합니다.

## 주의
- 서버가 메모리에 상태를 저장하므로, 서버를 다시 시작하면 입장 정보가 사라집니다. 기기에서 다시 입장해야 합니다.
- 중계 PC가 절전 모드에 들어가지 않도록 설정하세요.
- 방화벽에서 포트 8080을 학교 내부망에 한해 여세요. 학교 IT 허용 여부는 확인 중입니다.
- 휴대폰에서 소리와 깜빡임은 화면이 켜져 있는 동안 작동합니다.
