# 특수학급 비상호출 중계 서버 (학교 내부망 전용)

중계 PC(관리자 PC) 한 대가 서버 역할을 합니다. 선생님들은 전달받은 링크를 누르기만 하면 됩니다. 같은 학교 와이파이에서만 열리며, 외부 인터넷 주소에서 오는 요청은 서버가 거부합니다.

## 관리자 준비 (1회)
1. 중계 PC에 Node.js LTS를 설치합니다(nodejs.org). 설치 후에는 한 번도 다시 설치할 필요가 없습니다.
2. 이 폴더(hub)에서 학교를 등록합니다.
   node server.js add-school "학교명" "학교코드"
   학교 코드는 영문 대문자와 숫자 6~12자입니다.

## 매번 시작할 때
1. "시작하기.bat"을 더블클릭합니다.
2. 검은 창에 나오는 "선생님 접속 링크"를 복사해 학교 단체 대화방이나 문자로 전달합니다.
3. 이 창을 닫으면 서버가 꺼집니다. 열어 두십시오.

## 선생님 입장
전달받은 링크를 누르면 학교 코드가 이미 채워진 입장 화면이 열립니다. 이름, 역할, 교실을 고르고 입장하면 끝입니다. 휴대폰 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 다음부터 아이콘으로 바로 열 수 있습니다.

## 주의
- 중계 PC의 IP 주소가 바뀌면 링크도 바뀝니다. 관리자가 공유기에서 이 PC의 IP를 고정해 두는 것을 권합니다.
- 링크에 학교 코드가 들어 있으므로, 학교 밖으로 공개하지 마십시오.
- 서버는 기기 정보를 메모리에만 두며, 서버를 끄면 입장 정보가 사라집니다. 선생님들은 다시 입장하면 됩니다.
- 처음 실행할 때 Windows 방화벽 창이 뜨면 "개인 네트워크"에서 허용해 주십시오.
- 휴대폰에서 주소를 직접 입력할 때는 http://로 시작해야 합니다.
