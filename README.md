# 특수학급 비상호출 (v0.1.0, 시연 모드)

교사가 버튼을 누르면 같은 학교에 등록된 기기에서 알람(화면 깜빡임, 소리, 진동)이 울리고, 확인 버튼을 누를 때까지 반복됩니다.

## 현재 상태
- 시연 모드: 같은 브라우저 안의 여러 탭 사이에서만 호출이 전달됩니다.
- 알람음: 기본 경고음, 차임, 교사가 올린 음악 파일(2MB 이하, 기기 안 IndexedDB 저장).
- 시각 경고 켜기·끄기, 소리 켜기·끄기, 소리 크기 조절, 모의 훈련 호출.
- 설치형 웹앱(PWA): 홈 화면에 추가 가능.

## 실제 운영 전 필요한 일 (2단계)
1. js/config.js에 Firebase 설정값 입력(교수님 콘솔에서 복사).
2. 인증·호출 기록·기기 등록을 Firestore로 연결하고, FCM 웹 푸시로 등록 기기에 알림 발송.
3. iPhone·iPad는 홈 화면에 추가한 뒤 열어야 알림 권한을 요청할 수 있음(iOS 16.4 이상).
4. 잠금 상태에서 교사 음악 파일을 재생하려면 Android·iOS 래퍼 앱이 필요함(확인 필요).

## 안전 원칙
- 웹앱은 학교 비상벨·112 신고를 대신하지 않습니다.
- 호출 신호에는 학생 이름을 넣지 않고 교실과 시각만 넣습니다.
